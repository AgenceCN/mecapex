# MECApex — prototype web

Prototype statique, sans framework, prêt à être hébergé sur un hébergement HTML classique.

## Contenu
- `index.html`
- `assets/styles.css`
- `assets/app.js`
- `sources.md`

## Fonctionnement
- Les animations visuelles sont apportées principalement par des vidéos externes.
- Les interactions des cadres (survol, profondeur, inclinaison) sont légères et calculées côté navigateur.
- Les vidéos secondaires sont mises en pause lorsqu'elles sortent de la zone visible.
- Aucun moteur de particules lourd n'est inclus dans cette version.
- Le site est responsive.

## Mise en ligne
Déposer `index.html` et le dossier `assets/` à la racine de ton hébergement.

## Étape suivante recommandée
Remplacer progressivement les médias de démonstration par les vidéos/visuels industriels exacts que tu sélectionnes, idéalement auto-hébergés et compressés en plusieurs qualités.
